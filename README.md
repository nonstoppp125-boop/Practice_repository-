## GitHub Pages Deployment

This is a static site, so it can be published without a build system.

1. Upload the site files (`index.html`, `style.css`, `script.js`, `favicon.svg`, and any `assets` files) to the repository.
2. Open the repository on GitHub and go to **Settings**, then **Pages**.
3. Choose the publishing source (branch and folder) that matches how your repository is organized.
4. Save, wait a few minutes, then open the generated URL and check it in a browser.
5. Copy the working URL into the [Live Portfolio](#live-portfolio) section.

The Pages settings and deployment status must be checked separately in the repository. This README does not confirm that the site is live.
